# NutriLife — AI Context

Static website (HTML/CSS/JS) motivating Bulgarians toward healthy living. 5 pages, linear flow, dark theme. Python scraper for weekly grocery offers. All content in Bulgarian.

## Quick orientation

```
index.html → move.html → eat.html → start.html
"Оправдания"  "Движение"  "Хранене"    "Старт"

smart-food.html
"Smart Food" — отделен utility page/project за оферти и умно пазаруване, линкнат от NutriLife

smart-supplements.html
"Smart Supplements" — отделен utility page/project за цена на активна доза при добавки
```

Each page: fixed navbar with 5 dots (current page highlighted) + CTA button to next page.

## Coding rules

**General**
- Prefer proven libraries over hand-rolled code. Use `Fuse.js` for fuzzy search, `BeautifulSoup`/`requests` for HTML extraction, `pdfplumber` for PDFs.
- Don't add features, comments, error handling, or abstractions beyond what the task requires.
- Don't create new files unless necessary — extend existing ones.
- No backwards-compatibility shims. If something is unused, delete it.
- When a big problem takes multiple sessions to solve, document what was tried in a `NOTES.md` next to the relevant code.

**HTML/CSS**
- One CSS file (`css/style.css`) — no inline styles, no new CSS files.
- Reuse existing components: `.stat-card`, `.accordion-item`, `.info-box`, `.btn-green`, etc.
- Color modifiers `.green`, `.red`, `.amber`, `.purple` work on most components — use them instead of custom colors.
- All new text must have `data-i18n` or `data-i18n-html` attribute pointing to a key in `js/i18n.js`.
- Current copy workflow is BG-only. Do not add or update EN keys during normal content edits.
- `js/i18n.en.parked.js` exists only to preserve past EN work. Do not load it, merge it back, or spend tokens reading/editing it unless the task is explicitly about EN translations or re-enabling multilingual support.
- Responsive breakpoint is 480px — test mobile after layout changes.

**JavaScript**
- No frameworks — vanilla JS only. No new script files without a strong reason.
- DOM queries go inside `DOMContentLoaded` or the relevant `init*()` function.
- Tracker data uses localStorage key `nutrilife-tracker-YYYY-MM-DD`.
- Don't duplicate offer filtering logic — extend `renderOffers()` in `offers.js`.

**Python (scraper)**
- Read `scraper/NOTES.md` before changing scraper code.
- `data/offers.json` and `data/all_products.json` are generated — never edit manually.
- After any scraper run, always sync with `python sync_offers.py`.
- Scraper uses `SOURCE_PRIORITY`: structured DOM (3) > brochure listing (2). New sources must fit this ranking.
- Don't add new per-store scrapers to `scraper.py` directly — add to `scraper/store_scrapers.py` and import.
- Temporary/debug data files go in `data/` with a clear name prefix. Delete them when done — don't commit them.

```
python scraper/scraper.py   # → data/offers.json

```

Supports: Lidl, Kaufland, Billa, Fantastico, T-Market, Dar. Kaufland also has a PDF scraper (`kaufland_pdf_scraper.py`). Read `scraper/NOTES.md` before touching scraper code.

## Supplement scraper workflow

```
python scraper/supplement_scrapers.py   # → data/supplements.json
python sync_supplements.py              # → data/supplements.js (required for GitHub Pages)
```

Sources: Fitness1, HealthStore, Remedium, Framar, SilaBG, GymBeam, MyPharmacy, Mirabel, Ozone. Data is for price transparency only: price per active unit such as 5 g creatine, 1000 mg EPA+DHA, 100 mg magnesium, 1000 IU vitamin D3, 25 g protein, or 5 g fiber. Do not present supplements as medical advice or personalized recommendations. Mirabel/Ozone are included as best-effort sources but may produce no usable records if their product pages do not expose active-dose text.

## Offer JSON schema

```json
{
  "id": "string", "store": "Lidl|Kaufland|Billa|T-Market",
  "name": "string", "emoji": "🥚",
  "category": "protein|canned|grain|legume|dairy|nuts|fat|vegetable",
  "new_price": 3.49, "old_price": 4.29, "discount_pct": 19,
  "valid_until": "2026-01-19",
  "weight_raw": "500г", "weight_grams": 500, "price_per_kg": 6.98,
  "shelf_life": "1-2г|малотраен|...", "is_bulk_worthy": true,
  "health_score": 1-10,
  "diet_tags": ["high_protein","keto","mediterranean","vegetarian","budget"]
}
```

Health scores: 10 (риба тон, зехтин) → 9 (яйца, пилешко, леща, нахут) → 8 (овес, скир) → 7 (кисело мляко, сирене) → 6 (ориз, хляб)
